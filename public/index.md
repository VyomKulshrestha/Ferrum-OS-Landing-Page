# FerrumOS

FerrumOS is a bootable Rust x86-64 agentic and simulator-backed cyber-physical research operating system where an AI agent runs in Ring 3 and every effect remains subject to kernel-enforced authority.

## Claim boundary

FerrumOS v0.1.1 is the latest tagged software release. Current main contains newer research, including a simulator-backed cyber-physical tier with 152 passing contract tests and 32 passing model/decoder gates. FerrumOS is not a production-ready general-purpose OS or certified safety platform; no installed simulator/transport, native hypervisor, live EEG, medical, real robot, hard-real-time, or broad physical-PC claim is made.
